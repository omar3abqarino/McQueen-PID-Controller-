# McQueen-PID-Controller-
An implementation of a PID Controller in Python.

## The Main Equation for the PID Controller:
$$u(t) = K_p e(t) + K_i \int_{0}^{t} e(\tau) d\tau + K_d \frac{de(t)}{dt}$$
